FITSFiles.jl

FITSFiles.jl is a Julia implementation of the Flexible Image Transport System (FITS) file IO standard.

A FITS file is a vector of header-data units (HDUs), where the header of an HDU is a vector of cards, and fits reads the file.

FITSFiles.FITSFiles — Module

FITSFiles.jl is a Julia implementation of the Flexible Image Transport System (FITS) file format.

FITS files are composed of a vector of header-data units (HDUs), where an HDU is a header, which is a vector of cards, followed by data.

  • fits is the most common function for reading a file, and write writes it.
  • HDU creates a header-data unit.
  • Card creates, and parse reads, a card of a header.

FITSFiles.HDU — Type
HDU{T}(cards, data)
HDU([data, [cards]]; <keywords>)
HDU(cards; <keywords>)
HDU(type, missing, [cards]; <keywords>)
HDU(type, data, [cards]; <keywords>)

Create a header-data unit described by data and cards of type AbstractHDU.

The HDU function tries to determine the HDU type based on the data and cards. If only data is provided, then an array is interpreted as a Primary HDU and a Tuple or NamedTuple as a Bintable. If mandatory cards are provided, then they are used to determine the HDU type. Otherwise, the HDU type must be specified.

HDU types are: Primary, Random, Image, Table, Bintable, and Conform.

Arguments

  • data::U=missing: the binary or ASCII data, where U <: Union{AbstractArray, Tuple, NamedTuple, Missing}
  • cards::U=missing: the list of cards, where U <: Union{Card, Vector{Card}, Vector{Card{<:Any}}, Missing}

Keywords

  • record::Bool=false: structure the data as a list of records
  • scale::Bool=true: apply the scale and zero keywords to the data

The following keywords format the cards that are created, and are those of Card, which describes them.

  • append::Bool=false: append an ampersand to a string that is continued by a CONTINUE card
  • fixed::Bool=true: create fixed format cards
  • slash::Integer=32: index of the comment separator (/)
  • lpad::Integer=1: number of spaces before the comment separator
  • rpad::Integer=1: number of spaces after the comment separator
  • upad::Integer=1: number of spaces after the units
  • truncate::Bool=true: truncate a comment that is longer than the space at the end of the card

FITSFiles.Card — Type
Card(type, key, value, [units,] comment, format)
Card([key, [value, [comment]]]; <keywords>)
Card("HIERARCH", tokens, value, comment; <keywords>)

Create a card type, where type is Comment, Continue, End, Hierarch, History, Invalid, or Value{T}.

Arguments

  • key::AbstractString="": keyword string
  • value::U=missing: keyword value, where U is Missing, Bool, Integer, AbstractFloat, a Complex number of integers or floats, or AbstractString, which is the type T of the card Value{T}. Another type of value is an ArgumentError. A Quantity of a number may be given in place of the number, but a Quantity is not a type of value: the value of the card is the number, and the units of the Quantity are the units of the card. The units of a number without a Quantity are the unit string in square brackets at the beginning of the comment, e.g., [km/s] velocity, as they are for an image, and the unit string is removed from the comment. The comment of a string, a logical, a mandatory keyword, text that is not a unit string, or a scale factor, is not units.
  • tokens::AbstractString: the tokens of a HIERARCH keyword, which are separated by spaces
  • comment::AbstractString="": comment string

Keywords

  • append::Bool=false: append an ampersand to the string value, which marks that the string is continued by a CONTINUE card. A string that is longer than the card (>68 characters) is always split into a card and CONTINUE cards, which are returned as a vector.
  • fixed::Bool=true: use fixed format. A fixed-format number ends at byte 30, so a Float64 that has more than 20 characters is written with fewer digits of the mantissa, which are truncated, e.g., 1.2345678901234567e-100 is written as 1.2345678901234D-100. Use fixed=false to keep all of the digits.
  • slash::Integer=32: index of the comment separator (/). A value that passes the separator moves the separator to the right. A number in fixed format ends at the index 30, so the separator is at the index 32 or later. A comment, and the units, must end at or before the end of the card. If there is no space for the comment after the separator, the comment is dropped, or is continued at the index 32 on the CONTINUE cards of a string if truncate is false.
  • lpad::Integer=1: number of spaces before comment separator
  • rpad::Integer=1: number of spaces after comment separator
  • upad::Integer=1: number of spaces after the units string
  • truncate::Bool=true: truncate a comment that is longer than the space at the end of the card, and the comment of the card is the truncated comment. If false, the comment of a string is continued on CONTINUE cards of the string, and a comment of another value that does not fit, and units that do not fit, are an ArgumentError. A comment is dropped if the comment separator is at the end of the card.
  • warn::Bool=true: warn when a keyword longer than 8 characters creates a HIERARCH card
  • splitat::Union{Char, Nothing}=' ': split a long string and its comment into the cards after the last character that fits, instead of splitting at any character if nothing

FITSFiles.setvalue! — Method
setvalue!(card, value; <keywords>)

Return the card with the value value, and the units, format, and comment of the card. A number without units has the units of the card, or the units at the beginning of the comment of the card if the card has no units, as for the constructor of a card. A string that fits on the card, i.e., that has at most 68 characters, is not split, and moves the comment to the right if the string passes the comment separator. A string that does not fit on the card is split into the cards of a long string, the first card and the CONTINUE cards, which are returned as a vector, at the comment separator, or at the end of the card if there is no comment. The keywords are those of the constructor of a card, where the default of a layout keyword is the layout of the card.

Keywords

  • fixed::Bool: use fixed format. The default is the format of the card.
  • append::Bool=false: append an ampersand to the string value, which marks that the string is continued by a CONTINUE card.
  • slash::Integer: index of the comment separator (/). The default is the index of the separator of the card, and the index 32 or more for the separator of the cards of a long string.
  • lpad::Integer: number of spaces before the comment separator. The default is 0 if the separator follows the value of the card directly, and otherwise 1.
  • rpad::Integer: number of spaces after the comment separator. The default is the number of spaces of the card, or 1 if the card has no comment.
  • upad::Integer: number of spaces after the units string. The default is the number of spaces of the card, or 1 if the card has no units.
  • truncate::Bool=true: truncate a comment that is longer than the space at the end of the card, and otherwise continue the comment on the CONTINUE cards of a string, or raise an ArgumentError for another value.
  • splitat::Union{Char, Nothing}=' ': split a long string and its comment after the last character that fits, or at any character if nothing.

The card is replaced by the new card when a layout keyword is given, even if the value is the same.

source
Base.parse — Method
Base.parse(::Type{Card}, image::AbstractString; strict = true, units = true)

Parse 80 character card image from string buffer. A number with a lower case exponent letter (d or e) is not allowed by the standard, so it is an invalid card, unless strict is false. The units of a number, i.e., a unit string in square brackets at the beginning of the comment, are the units of the value, unless units is false or the keyword is mandatory.

The card is written as it is read, with the following exceptions, where the value is not changed: a number without an integer digit has a zero, e.g., .5 is 0.5; an exponent has at least two digits and a mantissa has one integer digit, e.g., E+007 is E+07 and 56.53E+13 is 5.653E+14; the sign of an integer zero is lost; and a number that is longer than before takes the spaces before the comment, but may move the comment, and the end of the comment of a full card is lost.

FITSFiles.formunit — Function
formunit(unit[, ufmt])

Return the ASCII string of a unit in the FITS standard (Sect. 4.3). The style of the string is ufmt, which has three characters: the separator of the units, a space, ., or *; / if a unit with a negative power follows a slash, or - if it has the negative power; and the style of a power, d for digits following the unit, ^, or * for **. The default is -d.

source
FITSFiles.parseunit — Method
parseunit(string)

Parse a unit string of the FITS standard (Sect. 4.3) and return the unit, or nothing if the string is not a valid unit string or has a unit that is not known. Units are multiplied by a space, ., or *, and divided by /, which may begin the string. A unit is raised to a power by an integer following the unit, by a decimal number or a ratio in parentheses following the unit, or by ** or ^ followed by an integer, a decimal number, or a ratio in parentheses. A scale factor, 10**k, 10^k, or 10+k, is followed by a unit and returns a quantity.
